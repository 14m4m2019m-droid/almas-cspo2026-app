طريقة تشغيل مشروع منصة الماس داخل Visual Studio Code

الملفات الأساسية:
1. index.html      لوحة التحكم الرئيسية
2. request.html    تسجيل طلب استشارة جديد
3. services.html   الخدمات والباقات وآلية العمل
4. styles.css      تنسيق الواجهة العربية RTL
5. script.js       العمليات والحفظ والتحليل والتقارير

طريقة التشغيل:
1. افتح برنامج Visual Studio Code.
2. من File اختر Open Folder.
3. اختر مجلد المشروع الذي يحتوي على الملفات الخمسة.
4. افتح ملف index.html.
5. اضغط بزر الفأرة الأيمن واختر Open with Live Server.
   إذا لم يكن Live Server مثبتاً:
   - افتح Extensions.
   - ابحث عن Live Server.
   - ثبته.
   - أعد فتح index.html ثم Open with Live Server.
6. سيعمل التطبيق على رابط محلي مثل:
   http://127.0.0.1:5500/index.html

ملاحظات مهمة:
- التطبيق لا يحتاج إنترنت أثناء التشغيل المحلي.
- البيانات تحفظ في المتصفح LocalStorage.
- لتجربة سريعة اضغط "إضافة بيانات تجريبية" في لوحة التحكم.
- لحفظ تقرير PDF اضغط "طباعة / حفظ PDF".
- لعمل نسخة احتياطية اضغط "تصدير البيانات JSON".
- عند نقل التطبيق إلى جهاز آخر، انقل الملفات الخمسة معاً.

طريقة النشر المجاني لاحقاً:
يمكن رفع الملفات الخمسة إلى GitHub Pages وتشغيلها كموقع مجاني.
